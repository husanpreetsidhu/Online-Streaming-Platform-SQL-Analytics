# 🎬 Online Streaming Platform SQL Analytics

## 📌 Project Overview

This project focuses on analyzing an online streaming platform using **MySQL**. It explores user behavior, subscription patterns, movie performance, viewing activity, and customer ratings through SQL queries.

The project demonstrates how SQL can be used to extract meaningful insights from structured data and solve real-world business questions.

## 🎯 Project Objectives

- Analyze user registrations and subscription patterns.
- Explore subscription revenue across different plans.
- Identify popular movies and genres.
- Understand user engagement and viewing behavior.
- Analyze movie ratings and customer preferences.
- Practice advanced SQL concepts through business-oriented queries.

## 🗂️ Database Structure

The project uses five main tables:

| Table | Description |
|---|---|
| Users | User details and registration information |
| Subscription | Subscription plans, prices, and dates |
| Movies | Movie titles, genres, and durations |
| Watch_History | User viewing activity |
| Ratings | Movie ratings and review dates |

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **IDE:** MySQL Workbench
- **Language:** SQL

## 📚 SQL Concepts Covered

- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate Functions: SUM, AVG, COUNT, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries and Nested Queries
- EXISTS, NOT EXISTS, IN, ANY, ALL
- Window Functions: ROW_NUMBER(), RANK(), DENSE_RANK()
- LAG(), LEAD(), FIRST_VALUE(), LAST_VALUE(), NTILE()
- Common Table Expressions (CTEs)
- Views
- Stored Procedures
- Business and KPI Analysis

## 📊 Business Analysis Areas

**User Analytics:** Registration trends, user activity, and engagement.

**Subscription Analytics:** Subscription distribution and revenue analysis.

**Content Analytics:** Popular movies, genre preferences, and movie performance.

**Rating Analytics:** Average ratings, highly rated movies, and user feedback.

**Platform KPIs:** Overall platform performance and key business metrics.

## 🚀 How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open the SQL file in MySQL Workbench.
3. Execute the database and table creation statements.
4. Import or insert suitable records into the tables before running the analysis queries.
5. Execute the queries to explore the different business questions.

**Note:** The SQL file contains database and table creation statements and analysis queries. A populated dataset is required to obtain query results.
